getPDF

  • getPDF(): Promise<string>

  • Generates a PDF document containing a list of publications.

    This method retrieves publication data, creates a PDF document, and adds pages with publication details. Each page includes the title, description, publication date, start date, end date, teacher's name, and tags. If the content exceeds the page height, a new page is added. The generated PDF is saved to the file system with a name that includes the current date.

    Returns Promise<string>

    The name of the generated PDF file.
